# BurnerEye Prediction Report

Отдельное настольное GUI-приложение для проверки эксперимента BurnerEye и
формирования PDF-отчёта с расчётами MAE/MAPE, анализом динамики качества,
распределением ошибок и выбором лучших/худших кадров.

## Возможности

- проверяет `results.csv`, обязательные поля, числовые данные, единицы,
  уникальность `frame_id`, папку `frames` и temporal-окна;
- объединяет физически одинаковые режимы после пересчёта `kg/h`, `g/h` и
  `g/s` в базовую единицу `g/h`;
- обнаруживает конфликтующие значения `trained_regime` и блокирует отчёт до
  ручного выбора;
- не изменяет исходные `results.csv` и изображения;
- рассчитывает только MAE и MAPE как итоговые метрики;
- анализирует весь эксперимент, обученные/необученные режимы, каждый режим,
  а также начало, середину и конец;
- формирует векторные графики прямо в PDF;
- сохраняет девять расчётных CSV и `processing.log`;
- проверяет сформированный PDF повторным открытием.

## Запуск

Требуется Python 3.10 или новее.

```powershell
py -3.10 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\run.bat
```

Или:

```powershell
.\.venv\Scripts\python.exe main.py
```

В окне приложения выберите папку, содержащую `results.csv` и `frames`.
Конфликтные режимы подсвечиваются. Выберите строки таблицы и назначьте им
итоговый статус, затем нажмите «Сформировать PDF-отчёт».

## Результат

Внутри выбранного эксперимента создаётся папка:

```text
prediction_report_YYYY-MM-DD_HH-MM-SS/
├── prediction_report.pdf
├── csv/
│   ├── overall_metrics.csv
│   ├── trained_untrained_metrics.csv
│   ├── metrics_by_regime.csv
│   ├── metrics_by_regime_stage.csv
│   ├── overall_stage_metrics.csv
│   ├── prediction_timeline.csv
│   ├── error_distribution.csv
│   ├── selected_frames.csv
│   └── regime_classification.csv
└── processing.log
```

CSV записываются в UTF-8 с BOM, чтобы русские подписи корректно открывались
в Excel. MAE и значения расходов в отчёте приводятся к `г/ч`; исходная
единица каждой строки сохраняется в `prediction_timeline.csv`.

## Особые случаи

- Нулевое фактическое значение участвует в MAE, но не в MAPE.
- Если MAPE-подобная оценка кадра невозможна, рейтинг использует
  нормализованную абсолютную ошибку; это отмечается в CSV и журнале.
- Отдельные отсутствующие кадры не исключают строки из расчётов.
- Для PDF нужен хотя бы один читаемый основной кадр `frames/<frame_id>.jpg`.
- При наличии менее четырёх кадров в отчёт входят все доступные без повторов.
