# 01. Сохранять строки с прогнозом одного расхода

Приоритет P1. Зависимости: нет. Labels: enhancement, input-format.

## Проблема

Оба реальных results.csv содержат все обязательные колонки, но по одному пустому прогнозу в каждой строке. `_parse_finite` исключает все 734 строки. Требуется семантика отсутствующего прогноза из FORMAT.md.

## Работа

- В `burner_eye_report/models.py` изменить predicted_fuel, predicted_steam и их *_g_h поля на `float | None`; поля отсутствующих абсолютных ошибок SelectedFrame тоже сделать optional. Сохранить возможность создавать старые PredictionRow без дополнительных обязательных аргументов.
- В `loader.py`, `_parse_row` отдельно разобрать необязательные прогнозы. Нормализацию единиц применять только к числам. Оба пустых прогноза исключать; оба фактических расхода всё ещё обязательны.
- Исправить проверку negative_flow: игнорировать None, но сохранить предупреждение о настоящих отрицательных числах. Не ослаблять валидацию идентификаторов, единиц и trained_regime.
- Добавить вычисляемое покрытие каналов на ExperimentData (либо эквивалент): число принятых прогнозов топлива/пара и доступные цели. Не определять цель по названию каталога.
- Агрегировать информацию о канале без прогнозов на уровне эксперимента, не создавать 734 одинаковых предупреждения.
