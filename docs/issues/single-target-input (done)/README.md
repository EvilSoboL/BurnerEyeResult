## Границы

Реализовать отдельные отчёты для прогноза пара, топлива и старого двухканального входа; безопасно обработать смешанную доступность прогнозов по строкам; не ломать вкладку сравнения. Дополнительные файлы необязательны для расчёта. Исходные видео и веса модели не нужны.

Объединение независимых моделей в общий двухканальный эксперимент, перепредсказание видео, исправление производителя экспорта и новая шкала времени по видеосекундам — отдельные возможные задачи. Здесь сохраняется текущий порядок по `timestamp` (время обработки), а видеовремя выводится как метаданные.
