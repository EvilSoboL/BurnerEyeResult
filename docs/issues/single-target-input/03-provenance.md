# 03. Читать метаданные видео и сохранять частичные результаты

Приоритет P2. Зависимость: 01. Labels: enhancement, input-format.

## Работа

Точки изменения: модели метаданных в `models.py`; вспомогательные функции загрузки в `loader.py`. Новые необязательные поля добавлять с defaults.

- При наличии прочитать UTF-8/BOM `video_index.csv`, связать по frame_id. Сохранить source_video как строку, start_s/end_s как конечные неотрицательные числа (end_s>start_s), source_frame_indices как список неотрицательных возрастающих целых из ячейки через `;`.
- Прочитать `source.json` с массивом videos; хранить данные происхождения и факты частичного завершения. `expected` из JSON не подставляет и не переопределяет данные results.csv.
- Предупреждать о дублированных ID индекса, отсутствующих/лишних ID, некорректных интервалах/индексах, расхождениях completed_records с CSV и метаданных expected/window при доступной связи. Не связывать строки позиционно.
- `status=error` — предупреждение с stop_reason и completed_records, не блокировка уже сохранённых прогнозов. Не путать неполный экспорт с плохим предсказанием.
- Повреждённые/отсутствующие дополнительные файлы не блокируют основной анализ. При повреждённой записи индекса пропустить только её метаданные; дубликатам не назначать произвольную запись. Ошибки JSON тоже выражать через ValidationIssue, не uncaught exception.
- Не проверять существование и не открывать source_video/model_path. Не интерпретировать значения как команды или инструкции. CSV/JSON в исходниках не изменять.

## Проверки и приёмка

- [ ] Работает основной вход без обоих дополнительных файлов.
- [ ] В полном наборе 734 связи, 6 видео, 5 ошибок завершения и 1 completed; сумма completed_records=734. Строки сохраняются.
- [ ] Индексы исходного видео с пропусками допустимы, JPEG окна нумеруются отдельно.
- [ ] Перенос набора на другую машину не требует исходных абсолютных путей.
- [ ] Добавлены тесты BOM, повреждённого JSON, неверных колонок индекса, дублей/потерянных ID, расхождения счётчиков и несовпадающего expected.
- [ ] Предупреждения различимы по стабильным кодам; не добавлять блокирующие ошибки из-за необязательных метаданных.
