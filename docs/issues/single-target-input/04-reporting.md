# 04. Формировать PDF и CSV с отсутствующим каналом

Приоритет P1. Зависимости: 02, 03. Labels: enhancement, input-format.

## Работа

Точки изменения: `reporting.py`, включая `_write_all_csv`, `_metric_fields`, `_frame_card`, распределения ошибок и выводы. Использовать прежний набор девяти CSV; новые колонки добавлять, старые сохранять.

- PDF явно указывает предсказываемую величину и покрытие: например, «Прогноз пара: 734; прогноз топлива: 0». Фактические расходы обоих каналов по-прежнему описывают режим.
- Для отсутствующего прогноза/ошибки выводить «Нет прогнозов» или прочерк с пояснением; MAPE при нулевом факте объяснять отдельно. Не создавать выводы о точности отсутствующего канала.
- CSV пишет None пустой ячейкой; добавляет счётчики MAE, доступность прогнозов и различимые причины исключения MAPE (`prediction_missing`, `expected_zero`, пусто для включённых). Причина отсутствия прогноза имеет приоритет, если одновременно факт=0.
- Проверить все `or 0.0` в гистограммах/распределениях: отсутствующие ошибки фильтровать, истинный 0 сохранять. Полностью пустую серию скрывать или показывать объяснение; не оставлять легенду с выдуманной линией/нулевыми столбцами.
- Карточки выбранных кадров и selected_frames.csv поддерживают отсутствие абсолютной ошибки одного канала и описывают метод рейтинга.
- Вывести доступные video metadata (имя видео, интервал окна, индексы или их краткое описание) в timeline/карточках; статус частичного завершения и причины — в validation-разделе и processing.log. timestamp обозначить временем обработки; не выдавать его за секунды исходного видео.
- Сохранить прежние условия наличия основных JPEG для одиночного отчёта, проверки PDF и исходных единиц.

## Проверки и приёмка

- [ ] Интеграционный тест строит PDF, все девять CSV и log для fuel-only и steam-only; открывает PDF через PdfReader и проверяет ключевые подписи/числа.
- [ ] Отсутствующий прогноз и ошибки — пустые CSV-ячейки; счётчики 0; настоящий нулевой прогноз и ошибка остаются числом 0.
- [ ] Гистограмма отсутствующего канала не содержит фиктивных наблюдений 0.
- [ ] Контрольные метрики полных наборов после чтения экспортных CSV совпадают с FORMAT.md в пределах точности записи CSV; до экспорта расчёт проверяется с допуском 1e-9.
- [ ] Визуально проверить страницы с общими метриками, режимом, графиками, предупреждениями и карточками для обоих каналов. Проверка через PdfReader одна не подтверждает отсутствие наложений.
- [ ] Существующий test_reporting проходит; исходники неизменны.
