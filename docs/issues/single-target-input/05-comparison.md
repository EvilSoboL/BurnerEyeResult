# 05. Сравнивать только доступные у обеих моделей величины

Приоритет P1. Зависимости: 02, 04. Labels: enhancement, input-format.

## Проблема

После поддержки None функция `metric_winner` объявит победителем сторону с единственной доступной метрикой. Это не сравнение качества. Два новых эксперимента имеют одинаковые режимы, но разные цели; их нельзя считать соперничающими по MAE/MAPE.

## Работа

Точки изменения: `comparison.py` (`analyze_comparison`, `ComparisonAnalysis`, `metric_winner`) и `comparison_reporting.py` (CSV, выводы, легенды и графики).

- Общие режимы по фактической паре расходов сохраняются. Доступность сравнения канала проверять на общих режимах, а не на всех строках исходных экспериментов.
- Если у одной стороны нет значения метрики → «Нет сопоставимых данных», без победителя. Если обе метрики числовые, сохранить прежние правила равенства/минимума. Отсутствующий MAPE из-за нулевого факта не мешает сравнению MAE.
- Если во всём пересечении режимов нет общего канала с прогнозами у обеих сторон, выдавать понятный ValueError до генерации отчёта. GUI должен корректно отобразить его (issue 06).
- Для двух моделей одного канала отчёт строится; для двухканальной и одноканальной — сравнивается общий канал. В отдельных общих режимах без покрытия писать отсутствие сравнения и сохранять данные о покрытии.
- В PDF/CSV не называть несопоставимый канал выигранным и не сводить качество разных целевых величин в общий рейтинг. `_regime_conclusion` и все вызовы metric_winner должны следовать тем же правилам.
- Не связывать записи разных экспериментов по frame_id или времени обработки; существующее сравнение агрегатов по режимам остаётся. Не добавлять объединение наборов.

## Проверки и приёмка

- [ ] Реальная пара «Расход пара» / «Расход топлива»: сообщение об отсутствии общей предсказываемой величины, без traceback и ложного отчёта победителя.
- [ ] Тесты: fuel/fuel, steam/steam, both/fuel, fuel/steam, None у одной стороны, равные числовые метрики, общий канал только вне общих режимов.
- [ ] Смешанное покрытие по режимам не создаёт ложных победителей.
- [ ] Сравнительный PDF и CSV одного канала открываются; пропущенные серии корректны; можно сравнивать без frames как раньше.
- [ ] Существующие test_comparison проходят; если они проверяли победителя при None, обновить ожидание с обоснованием нового контракта.
