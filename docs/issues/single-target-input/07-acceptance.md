Конкретные входы перечислены в FORMAT.md. Сначала повторить `inspect_inputs.py` и сравнить SHA-256 с evidence.json. Если данные изменены, не подгонять код под старые числа: пересчитать и объяснить изменение эталона.

- [ ] Для каждого набора: total_csv_rows=734, rows=734, excluded_rows=0, regimes=6; все trained; покрытие собственного канала=734, другого=0.
- [ ] Проверить чтение JPEG: ожидаются 734 основных и 734 окна по 32 кадра; число реально читаемых изображений фиксировать отдельно. При повреждении применяется прежняя валидация, а не молчаливое игнорирование.
- [ ] Совпадение MAE/MAPE с FORMAT.md с абсолютным допуском 1e-9 до округления.
- [ ] Нет блокировки из-за пяти source videos со status=error; предупреждения есть в GUI, PDF и log.
- [ ] Созданы и открываются два отдельных PDF; проверены CSV и ключевые страницы визуально.
- [ ] Сравнение этих двух наборов сообщает отсутствие общего канала. Сравнение переносимых моделей с одинаковым каналом успешно.
